# FatLine v0.2.0 beta 2

**Update/install fix for v0.2.0 beta 1.** Beta 1 used Android `versionCode=10001`, lower than the latest Android CI builds (`10266`), because GitHub run numbers are unique **per workflow**, not shared across workflows. Android correctly refused to install the older code as an update.

This release fixes the cause by deriving the Android version code from GitHub's globally ordered workflow **run ID**, shared across Android CI and release builds. The APK package remains `dev.scanrelay.app` and the test-signing certificate stays the same.

## Install or update

Download **FatLine-v0.2.0-beta.2-debug.apk** from **Assets** and install it over your existing FatLine app. **Do not uninstall** the existing app: uninstalling can remove saved scanner profiles and preferences.

This build uses the same stable **CI debug test key** as earlier FatLine CI builds. It is for personal testing and is not production/Play Store signed.

## Included features

- New radio-tower and waveform FatLine launcher icon with Android adaptive icon support
- Automatic History/archive refresh on tab entry and reconnection, retaining applied archive filters
- Compact playing status and a Call actions menu instead of the duplicate large Now Playing card
- Independent Play audio / Stop audio mode: silence scanner output while keeping your authorized server sessions and local transcript keyword alerts active in the background
- Multi-scanner playback, live recent-call tap-to-play, history/replay, durable audio queue, reconnect recovery, channel tree, scan lists, and Android Auto
- Self-hosted endpoint privacy restrictions, no tracking or duplicated advertising

## Remaining verification

Device testing is still needed for background alerts with the screen locked, reconnection and Wi-Fi/cellular transitions, Android Auto, and encrypted audio servers. Android power-management and notification settings may restrict background alerts.

Built using Android CI unit tests, resource compilation, test-key signing verification, and a check that the new APK's version code exceeds `10266`.
